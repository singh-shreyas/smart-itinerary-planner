# Project Documents

Everything written about the project, in one place. The code itself is explained in the main [README](../README.md).

| Document | What it is |
|---|---|
| [Presentation Slides](presentation-slides.pdf) | The slide deck for the project presentation |
| [Algorithms Handbook](algorithms-handbook.pdf) | Every algorithm in the project: what it does, where it is used, pseudocode, complexity, and tested Python and C code ([source files](algorithm-code/)) |
| [How the Planner Works](how-the-planner-works.pdf) | The whole workflow in plain, non-technical words, from the form to the finished plan |
| [Technical Documentation](technical-documentation.pdf) | How the system is built: architecture, algorithms and data |
| [User Journey and Workflow](user-journey-and-workflow.pdf) | How a traveller uses the website, step by step |
| [Workflow, One Page](workflow-one-page.pdf) | The whole workflow as a single diagram ([image](workflow-one-page.png)) |
| [Viva Handbook](viva-handbook.pdf) | Questions and answers prepared for the project viva (oral examination) |

## Folders

| Folder | What it holds |
|---|---|
| [`algorithm-code/`](algorithm-code/) | Short, self-contained versions of each algorithm in Python and C, as printed in the Algorithms Handbook. They mirror the real implementations in [`algorithms/`](../algorithms/) but run on their own, without the app. |
| [`word-sources/`](word-sources/) | Editable Word versions of the technical documentation, the user journey guide and the viva handbook. |
