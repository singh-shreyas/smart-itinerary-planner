How the overall score is calculated

Each measure is first compared within this trip: for “higher is better” measures the subscore is 100 × value ÷ best value; for travel per place (lower is better) it is 100 × best ÷ value. So minutes, rupees and counts are never added together directly. The overall score is the weighted sum: {% for k, w in weights.items() %}{{ (100 * w)|round|int }}% {{ {'value': 'value', 'coverage': 'coverage', 'travel': 'travel efficiency', 'utilisation': 'time utilisation', 'budget': 'budget efficiency'}[k] }}{{ ', ' if not loop.last else '.' }}{% endfor %} Value carries the most weight because it is what the planner tries to maximise; coverage and time use matter to a traveller; travel and budget efficiency break ties between similar plans.

Feasibility is a gate, not a weight: a plan with any constraint violation is never recommended. Runtime is shown but not scored, because a few milliseconds do not change anyone's day. {% if 'budget' not in weights %}No plan spends anything here, so budget efficiency is left out and the other weights are scaled up.{% endif %}
